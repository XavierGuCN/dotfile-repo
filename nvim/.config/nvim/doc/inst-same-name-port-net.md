# Inst Same-name Port and Net

重启 Neovim 后，在 Verilog/SystemVerilog 文件中，光标所在行只需写 `xxx` 或 `.xxx`：

- 插入模式：按 `Ctrl-g`，松开后按 `p`。
- 普通模式：按 `<leader>vp`（LazyVim 默认是空格、v、p）。
- 命令：`:InstSameNamePortNet`。

为端口与同名网络生成连接 `.xxx (xxx)`，插入模式继续保持，输入位置在括号内信号名末尾。
支持行尾 `// 注释`。已有 `.xxx(expr)` 保持原样。

从同一实例内最近的完整端口推断点号、左右括号的列，距离相同时优先上方。
左右括号分别判断：放得下就对齐，放不下就自然展开；名称与左括号至少留一个空格。
不会调整其他端口的空格。没有参考端口时保留当前缩进。

当前项后面还有端口则添加逗号；若后面仅有空行、注释和列表结束括号则不添加。
如果前一项是缺少逗号的完整连接，会补上它的逗号。尚未生成连接的名称保持原样，等待各自触发。
一次触发可一次撤销。

支持普通模块实例和 `#(...)` 参数化实例。端口须各占一行，列表的结束括号须已存在且另起一行。
第一版不处理实例数组、转义标识符、多行连接、条件编译端口列表或同一声明中的多个实例。
无法识别时提示原因并保留原文。扫描时会忽略注释和字符串中的括号。

验证命令（在 Neovim 配置目录执行）：

```sh
nvim --headless -u NONE -i NONE -n -l tests/inst_same_name_port_net.lua
```
